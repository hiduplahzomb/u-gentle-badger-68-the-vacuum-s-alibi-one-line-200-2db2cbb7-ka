One line, 200 characters or fewer: the funniest excuse a robot vacuum can give for missing a spot.

The vacuum did not miss the spot. The dust filed a restraining order, and the vacuum's firmware respects court orders. Deadpan robot voice, legal procedure as alibi.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and verifies it byte-for-byte.
